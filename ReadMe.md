**WRA-Coplur Assignment** - *Gaurav Sharma*

*Assignment:*

Given a large list of integers, find the length of the longest contiguous subarray whose sum is exactly K. The array may contain positive, zero, and negative values, and its size can be up to 10⁶. Design an efficient solution that avoids O(n²) time complexity. Example 1: Input: arr = [10, 5, 2, 7, 1, 9], K = 15 Output: 4 Explanation: The longest subarray is [5, 2, 7, 1], whose sum is 15. Example 2: Input: arr = [-5, 8, -2, 4, 3, -8, 6], K = 5 Output: 5 Explanation: The longest valid subarray is [8, -2, 4, 3, -8], whose sum is 5.
